# SauceDemo – Manual Testing Project

## Project Overview
This is a self-directed manual software testing project using the SauceDemo demo e-commerce website.

The objective was to understand and practise manual testing concepts through real website interactions.

## Application Under Test
- Website: https://www.saucedemo.com/
- Testing Type: Manual Testing
- Testing Scope: Login, Product Listing, Shopping Cart and Checkout
- Test Cases: 15

## Testing Activities
- Created a basic test plan.
- Designed positive and negative test cases.
- Executed test cases manually.
- Recorded actual and expected results.
- Documented execution status.
- Prepared a defect report.
- Created a test execution summary.

## Test Execution Summary
- Total Test Cases: 15
- Passed: 15
- Failed: 0
- Blocked: 0
- Not Run: 0
- Defects Reported: 0

## Tools Used
- Google Chrome
- Microsoft Excel / LibreOffice Calc
- GitHub

## Project Limitation
This was a self-directed learning project conducted on a publicly available demo website. It does not represent production application testing.

## Learning Outcome
Gained practical exposure to test case design, positive and negative testing, test execution, result documentation and basic defect reporting.
